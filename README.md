# 🍣 Itadakimasu Restaurant

### Website Institucional & Cardápio Digital — Culinária Japonesa

Projeto de interface web desenvolvido como avaliação acadêmica para a graduação em Análise e Desenvolvimento de Sistemas (ADS). O objetivo do projeto foi adaptar e refatorar uma landing page institucional para um restaurante temático, focando na apresentação visual do cardápio, responsividade e experiência do usuário.

---

## 🔗 Demonstração
Acesse a versão ativa do projeto online:  
👉 **[Visualizar Website em Produção](https://landing-page-gastronomica-restauran.vercel.app/)**

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das seções e conteúdos.
* **CSS3 / Bootstrap:** Estilização visual, regras de media queries para responsividade mobile e personalização de componentes.
* **JavaScript:** Interatividade de componentes (Swiper.js / Carrosséis).
* **Vercel / GitHub:** Versionamento do código-fonte e deploy da aplicação.

---

## 📌 Destaques do Projeto

- Layout totalmente adaptado para telas mobile e desktop.
- Seções dedicadas para apresentação de cardápio, reservas de mesa e formulário de contato.
- Ajustes finos de CSS para sobrescrever a estilização padrão de framework e garantir fidelidade visual.
